🚀 NEXORA – Explore Beyond the Universe

NEXORA is an interactive space exploration website where you can discover planets, galaxies, space missions, and amazing NASA photographs.

🌌 Live Website: https://subha445.github.io/nexora-space-explorer/

✨ Features

- 🪐 Solar System Explorer – Explore planets and discover interesting facts.
- 🌍 Interactive Solar System – Watch planets orbit around the Sun.
- 🌌 Galaxy Explorer – Discover galaxies, nebulae, and black holes.
- 🚀 Space Missions – Learn about famous space missions.
- 🧠 Space Quiz – Test your space knowledge.
- ⭐ My Galaxy – Save your favourite discoveries.
- 📸 NASA Space Gallery – Explore real NASA space photographs.
- ⚖️ Planet Weight Calculator – Calculate your weight on different planets and the Moon.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- NASA Images API
- Local Storage
- GitHub Pages

🎨 Design

NEXORA features a cosmic design with:

- Dark space backgrounds
- Purple and blue glowing effects
- Animated stars and planets
- Interactive cards and sections
